# Dashboard enhancements

All 30 requested improvements are implemented in the published dashboard:

1. Text-free generated hero artwork.
2. Separate transparent subject icons coordinated with the reference.
3. Short mobile hero with a compact artwork strip.
4. Sticky four-section mobile bottom navigation.
5. Expanded mobile search on focus.
6. Live subject, platform, and Android app suggestions with keyboard navigation.
7. Dedicated clear-search button.
8. Live result count.
9. Empty state with a reset action.
10. Category colors and badges.
11. Category overflow scroll button.
12. Last category stored in the browser.
13. Consistent card structure and heights.
14. Minimum 44-pixel primary touch controls.
15. Stronger description contrast in both themes.
16. Lab/platform/app destination labels.
17. Explicit shared-platform labels.
18. Saved favorites.
19. Recent website and app destinations, with clear history.
20. Featured IQ Labs resource.
21. Pinned quick-launch resources.
22. Subject overview dialogs with destination and related subjects.
23. Coordinated app icons, descriptions, and Google Play actions.
24. Consistent rounded action controls.
25. Refined dark theme and transparent artwork.
26. Light, Dark, and Device theme options.
27. Scroll-aware section navigation.
28. Back-to-top control.
29. Focus indicators, skip link, accessible status feedback, keyboard tabs/dialogs, and reduced-motion support.
30. Simplified footer with grouped information and navigation.

Favorites, pins, recent resources, theme, and category use browser-local storage. They do not sync across devices. Shared destinations use the links supplied by the user; no dedicated URLs were invented.

Artwork was generated using the built-in ImageGen tool. Final assets are `dist/assets/hero-v2.png`, `dist/assets/icons-atlas-transparent.png`, and the 24 individual PNGs in `dist/assets/icons/`.

Prompt briefs: a text-free blue futuristic science lab with a central holographic neural brain; a 6-by-4 glossy 3D educational icon atlas matching the reference, followed by alpha background extraction while retaining the layout.
